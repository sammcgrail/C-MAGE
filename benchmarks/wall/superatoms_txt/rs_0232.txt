I read the two wedged methyl stereocentres as follows, taking the implied hydrogen as pointing back in each case:
- **Top carbon:** methyl, ring CH2 and N run clockwise, which gives `[C@@H]` when written as `N1[C@@H](C)C...`.
- **Bottom-left carbon:** methyl, N and ring CH2 run clockwise, which gives `[C@H]` when written as `...C[C@H]1C`.

The indane C2 carries no wedge, so it has no stereo label.
