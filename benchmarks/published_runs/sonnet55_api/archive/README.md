# Superseded readings

The first 50 corpus images were first read with an earlier prompt (`prompt_v1.txt`, max_tokens
16,000). They were re-read with the published prompt (`../prompt_v2.txt`, max_tokens 64,000,
streamed, same model) and those readings replaced them in `../ledger.jsonl` and `../raw/`. The
superseded rows and their raw responses are kept here; their cost still counts in the tab's total.
